# 移动端语言听写练习工具（sologsb-1029）

面向手机使用的听写练习应用，包含学习端和教师反馈视图。课程、未提交答案、练习进度、逐词结果与反馈均保存在浏览器本地，可离线继续已下载课程。

## 功能

- 课程库：按课程和课节展示难度、句数、预计时长与下载状态。
- 离线课程：可切换课节下载标记；首次访问后由 Service Worker 缓存应用壳，断网重开仍可进入已下载课程并继续编辑。
- 听写流程：调用浏览器语音合成播放完整句子，输入答案后按句导航或整课提交。
- 逐词判错：使用词级序列比对识别拼写、漏词和多余词，并生成单句与整课得分。
- 错误复核：错误词可单独重听；可选择起止词重听指定片段；可为每个错误选择类别并记录原因。
- 教师反馈：教师视图可选择学生作答并写入反馈，反馈会回显在学习记录中。
- 错题复习：提交后错词按原课程、原句与稳定词位自动进入复习队列；只练仍有错词的句子，同一词连续答对两次才移出队列，答错则回到队首并清零连续次数；队列进度与复习草稿可跨刷新恢复。
- 进度恢复：保存每句答案和当前句，刷新、切换应用或手机旋转后可恢复。
- 可访问性：支持浅色/深色模式、五档字号区间、触控尺寸、键盘提交和减少动态效果偏好。
- 记录导出：将练习历史、逐词结果、错误分类、原因、教师反馈、当前错题复习队列以及每次复习结果导出为 JSON。

## 技术栈

- Vue 3
- TypeScript 5
- Varlet UI
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器监听 `0.0.0.0`，适合通过局域网在手机浏览器中测试。宿主机正式端口按根目录 `docker-compose.yml` 映射为 `10029:80`。

## 类型检查与生产构建

```bash
npm run typecheck
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1029 .
docker run --rm -p 10029:80 sologsb-1029
```

最终镜像仅包含 nginx 和静态构建产物，nginx 监听容器 `80`。

## 数据说明

浏览器存储键为 `sologsb-1029-dictation-state-v1`（沿用旧键，`schemaVersion: 2` 会在加载时自动从 v1 迁移：历史练习、教师反馈与进度原样保留，并按历史错词回填复习队列）。导出文件为 UTF-8 JSON，包含 `attempts`、`progress`、`reviewQueue`、`reviewResults`、`activeReview` 与 `reviewDrafts`，可用于后续学习分析。

### 错题复习规则

- 队列条目的唯一标识为“课节 + 句子 + 稳定词位”（原文词索引；多词项额外带上实际词形），跨提交对齐方式变化也能定位到同一个词。
- 在结果页调整错误分类或原因时，会同步更新队列中的同一条；历史记录中的逐词结果也会更新。
- 同一个词再次提交仍错，连续答对次数清零并作为新错词移到队尾。
- 复习只抽取队列中仍存在错词的句子；某词连续答对两次即移出队列，答错则清零并提到队首，所在句子回到本轮最前面。
